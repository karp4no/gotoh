# Fundamentos de Programação

## O que é programação?

Programação é o processo de criar instruções para que um computador execute determinadas tarefas.

## Algoritmo

Um algoritmo é uma sequência de passos para resolver um problema.

Exemplo:

1. Receber dois números.
2. Somar os números.
3. Mostrar o resultado.

## Variáveis

Variáveis são espaços utilizados para armazenar valores durante a execução de um programa.

Exemplo em Python:

nome = "Rodrigo"
idade = 21

## Condicionais

Condicionais permitem que o programa tome decisões.

idade = 18

if idade >= 18:
    print("Maior de idade")

## Loops

Loops permitem repetir determinadas instruções.

for numero in range(5):
    print(numero)

## Funções

Funções agrupam instruções que podem ser reutilizadas.

def somar(a, b):
    return a + b
